# Nox на iPhone — бесплатная установка через Xcode

Проект iOS уже существует и собирается. Он сделан на Capacitor: это тонкая
оболочка вокруг `WKWebView`, которая открывает боевой `https://noxchat.ru`.
Ничего создавать заново не нужно — нужно подписать своим Apple ID и запустить.

Проверено на этой машине: `xcodebuild ... -sdk iphonesimulator` →
**BUILD SUCCEEDED** на Xcode 16.2.

## Первый запуск, по шагам

1. **Установи Xcode** из App Store, открой один раз и согласись с
   компонентами, которые он попросит доустановить.

2. **Открой проект.** В терминале из корня репозитория:

   ```bash
   open ios/App/App.xcodeproj
   ```

   Именно `.xcodeproj`, не `.xcworkspace` — здесь нет CocoaPods, зависимости
   подтягиваются через Swift Package Manager. При первом открытии Xcode
   потратит минуту на их загрузку; дождись, пока в верхней строке пропадёт
   индикатор.

3. **Добавь свой Apple ID.** Xcode → Settings → Accounts → «+» → Apple ID.
   Обычная бесплатная учётная запись, платить не нужно.

4. **Подключи iPhone кабелем.** На телефоне разреши «Доверять этому
   компьютеру».

5. **Включи режим разработчика на iPhone.** Настройки → Конфиденциальность и
   безопасность → Режим разработчика → включить → перезагрузка. Пункт
   появляется только после того, как телефон хотя бы раз был подключён к
   Xcode, так что делай это после шага 4.

6. **Выбери подпись.** В Xcode слева нажми на синюю иконку `App` вверху
   дерева файлов → вкладка **Signing & Capabilities** → цель **App**:
   - поставь галочку **Automatically manage signing**;
   - в **Team** выбери свою строку вида `Имя Фамилия (Personal Team)`.

7. **Если Xcode ругается на Bundle Identifier.** Ошибка звучит примерно как
   «The app identifier cannot be registered to your development team». Значит
   идентификатор `ru.nox.messenger` уже занят чужой учётной записью. Поменяй
   его тут же, в поле **Bundle Identifier**, на любой свой уникальный —
   например `ru.nox.messenger.имя`. Больше нигде менять не нужно: на работу
   приложения это не влияет, оно всё равно открывает тот же сайт.

8. **Выбери устройство.** В верхней панели Xcode, где написано имя схемы,
   выбери свой iPhone (не симулятор).

9. **Нажми Run** — треугольник слева вверху, или `Cmd+R`.

10. **Первый запуск на телефоне упрётся в доверие.** iPhone скажет
    «Ненадёжный разработчик». Открой Настройки → Основные → VPN и управление
    устройством → выбери свою учётную запись → «Доверять». После этого
    запусти приложение с домашнего экрана.

## Важно про бесплатную учётную запись

**Подпись живёт 7 дней.** С бесплатным Apple ID сертификат разработчика
действует неделю; после этого приложение перестанет открываться с ошибкой о
недоверенной подписи. Лечится повторным нажатием Run в Xcode с подключённым
телефоном — переустанавливать и терять данные не нужно.

Другие ограничения Personal Team, которые здесь реально имеют значение:

- **Push-уведомления не работают.** Они требуют платного Apple Developer
  Program. В проекте намеренно нет ни одного платного capability и нет файла
  entitlements — именно поэтому бесплатная подпись проходит. Уведомления
  внутри открытого приложения работают как в браузере.
- **Не более трёх приложений** от одной бесплатной учётной записи
  одновременно.
- **Только по кабелю или локальной сети**, без TestFlight и без раздачи
  ссылкой.

## Что в оболочке сделано руками

`NoxViewController.swift` — подкласс моста Capacitor. Делает две вещи, которых
Capacitor по умолчанию не умеет:

- **статус-бар следует теме Nox, а не системной.** Веб-слой сообщает текущую
  тему через `window.webkit.messageHandlers.noxTheme`, контроллер меняет цвет
  глифов. Без этого при системной светлой теме и тёмной теме Nox часы и батарея
  были чёрными на чёрном.
- **под вебвью никогда не белый фон.** Холодный старт, возврат из фона и
  оттяжка за край показывают то, что лежит под веб-слоем; Capacitor оставляет
  там белый. Теперь это цвет фона темы.

`LaunchScreen.storyboard` — только адаптивный цвет `LaunchBackground`, без
графики. Логотип на launch-экране не рисуется намеренно: экран запуска не может
прочитать тему приложения, поэтому любой знак был бы неправильным в одной из
двух схем, а второй, светлый вариант знака пришлось бы придумывать — бренда с
таким вариантом не существует. Фон совпадает с `--background`, поэтому переход
к веб-слою не виден.

**Не добавляй сюда комментарий выше корневого тега `<document>`** — `ibtool`
падает на нём с «Interface Builder can't determine the type».

`UIBackgroundModes` содержит только `audio` — он держит аудиосессию WebRTC при
свёрнутом приложении. `voip` убран: он работает только для приложения с
`PKPushRegistry`, а PushKit в проекте нет.

## Что приложение уже умеет

Оболочка Capacitor использует `WKWebView` с постоянным хранилищем, поэтому:

- **вход сохраняется между запусками** — сессия в cookie переживает закрытие
  приложения;
- **сокет и обмен сообщениями в реальном времени** работают так же, как в
  Safari — это тот же движок;
- **выбор файлов и фото**, камера и микрофон разрешены: в `Info.plist` уже
  лежат нужные описания на русском.

## Если что-то пошло не так

**«No account for team»** — не выбран Team на шаге 6.

**«Failed to register bundle identifier»** — шаг 7, поменяй идентификатор.

**Приложение открывается белым экраном** — проверь, что телефон в сети и что
`https://noxchat.ru` открывается в Safari на нём же. Оболочка ничего не
кеширует сама, она показывает боевой сайт.

**«Untrusted Developer»** — шаг 10.
