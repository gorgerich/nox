# Nox Product Context

register: product

## Purpose

Nox is a private messenger for daily chats, calls, groups, contacts, and profile management.

## Users

Users open Nox many times per day on mobile. They need fast trust: chat opens quickly, controls are familiar, status is clear, media feels native.

## Design Goal

Quiet premium utility. The interface must disappear behind people and messages. Use delight only as tactile feedback: press, reveal, send, sheet, tab selection.

## Anti-References

- Generic AI gradients and colorful ambient blobs.
- Decorative glass everywhere.
- Hard shadows between list rows.
- Oversized cards, marketing layout, uppercase labels.
- Motion that delays task flow.
